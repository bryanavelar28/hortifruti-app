# Feira Verde

Aplicativo web de hortifruti em português, com busca, categorias e cesta de compras. O catálogo usa produtos e preços demonstrativos, em reais. A cesta é salva no navegador e a lista pode ser copiada para compartilhar.

## Executar

Sirva a pasta com `python3 -m http.server 8080` e acesse `http://localhost:8080`. O aplicativo usa HTML, CSS e JavaScript, sem dependências de instalação.

Edite a lista `products` em `app.js` para ajustar o catálogo. Os preços são armazenados em centavos. A foto da feira é do [Unsplash](https://images.unsplash.com/photo-1542838132-92c53300491e).
